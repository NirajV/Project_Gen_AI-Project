# Project_Gen_AI-Project

A multi-branch project repository featuring portfolio and generative AI initiatives.

## 📁 Projects

### [Portfolio Website](/portfolio/)
A modern, responsive portfolio website showcasing professional profile and experience.

**Tech Stack**: Next.js 14, TypeScript, Tailwind CSS
**Status**: ✅ Complete - Ready to deploy

**Quick Start**:
```bash
cd portfolio
npm install
npm run dev
# Open http://localhost:3000
```

**Features**:
- Professional dark-themed design
- Fully responsive (mobile, tablet, desktop)
- Smooth navigation and scroll effects
- SEO optimized
- Ready for production deployment

**Build for Production**:
```bash
cd portfolio
npm run build
npm run start
```

## 🌿 Branch Strategy

- **Development**: Primary integration branch for feature work
- **QA-UAT**: Quality assurance and user acceptance testing
- **Production/Prod**: Production-ready releases
- **main**: Legacy/backup branch
